Windows

For Windows 10 or later, 64-bit.

Download for Windows

Version 1.4.0 · Windows 10 or later · 64-bit PC

How to install on Windows
  1. Download and extract the ZIP file.
  2. Keep the MediaFlow folder together, then open MediaFlow.exe.
  3. Paste a YouTube or Spotify link, choose where to save, and click Download.

The app saves each song to your computer as it finishes. Spotify provides track information; the app finds matching audio from public sources and does not download Spotify’s protected stream.

This Windows build is unsigned and may show a SmartScreen notice. The release includes the source and third-party notices.

Download for Apple Silicon Download for Intel Mac

Version 1.3.0 · macOS 12 or later · Apple Silicon means M1 or later.

How to install and use
  1. Open the downloaded disk image.
  2. Drag the app into Applications, then open it.
  3. Paste a YouTube or Spotify link, choose where to save, and click Download.

The app saves each song to your Mac as it finishes. Spotify provides the track list; the app finds matching audio from public sources. It does not download Spotify’s protected audio stream.

This independent app is not Apple-notarized. If macOS blocks the first launch, follow Apple’s first-open instructions after checking the release and source.

About this website

This website does not accept playlist links or process downloads. Downloads run in the app on your computer; visitors cannot use this site’s cloud service to download media.

Only download media you own or have permission to save, and follow the source platform’s terms.
